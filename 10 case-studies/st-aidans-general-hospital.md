# St Aidan's General Hospital — Partial system migration, full data conversion

**Organisation.** A 500-bed community hospital with an existing EHR approximately ten years old. Clinical team competent and digitally capable, but resistant to wholesale workflow disruption. The organisation wanted primary terminology for the workflows where clinical granularity mattered most.

**Approach.** Full data migration for all historical clinical records, combined with targeted system migration on two workflows: problem list and allergy capture. Both of these received new SNOMED CT primary-terminology interfaces. All other workflows — prescribing, lab review, results, discharge summaries, clinic letters — kept the existing interface unchanged.

**Terminology strategy.** Mixed: primary for problem list and allergies; reference for all other workflows.

**System and data migration.** Partial system migration (two workflows) and full data migration.

**Outcomes.** Clinical granularity significantly improved on problem lists and allergy capture. Decision support quality improvement measurable within three months (drug-allergy alert accuracy increased by 23% relative to the pre-migration baseline). Half-day retraining per clinician compared to several days for a full system migration.

**Lessons.** The decision about which workflows to move to primary terminology — and which to leave at reference — required genuine clinical input. An early proposal to include prescribing in the primary-terminology set was rejected by senior clinicians; retaining the familiar prescribing interface and adding SNOMED CT in the background was sufficient for that workflow. Clinical ownership of the scope decision was a significant factor in adoption success.

**Typical profile.** 18–36 months, single-digit millions for a mid-sized hospital.
